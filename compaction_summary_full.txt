### 3. Key Findings & Architecture Decisions
- **Fen Structure Interleaving:**
  In Fen Bilimleri, activities in the textbook are separated and numbered per Bölüm (e.g. 1. Bölüm Etkinlik 1–15, 2. Bölüm Etkinlik 1–21).
  The chronological order in each unit:
  - Bölüm 1: Etkinlikler -> Kavratan Test 1 -> Bumerang Test 1
  - Bölüm 2: Etkinlikler -> Kavratan Test 2 (..3) -> Bumerang Test 2 (..3)
  - Bölüm 3 / Final: Etkinlikler -> Kavratan / Bumerang -> Beceri Temelli -> Bağlam Temelli -> Yazılıya Hazırlık.
- **Türkçe Structure Interleaving:**
  In Türkçe, activities run 1 to N continuously per Tema (e.g. Tema 1 has 39 activities).
  Sections:
  - Söz Varlığı: `slice_dict(ETKINLIKLER, 1, 12)` + Bilgi ve Kavrama Testleri + Bumerang Test 1
  - Metinde Anlam: `slice_dict(ETKINLIKLER, 13, 25)` + Bilgi ve Kavrama Testleri + Bumerang Test 2
  - Dil Yapıları: `slice_dict(ETKINLIKLER, 26, 35)` + Bilgi ve Kavrama Testleri + Bumerang Test 3
  - Yazım Noktalama: `slice_dict(ETKINLIKLER, 36, 39)` + Bilgi ve Kavrama Testleri + Bumerang Test 4 + Zenginleştirme + Beceri + Bağlam + Yazılıya Hazırlık.
- **Start Question Numbering Integrity:**
  Every sliced open-ended test must include `startQuestionNumber` in `__meta` matching the start of the slice so the UI renders original textbook numbers.
